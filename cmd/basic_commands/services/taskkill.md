```
taskkill /f /t /pid 998
```




`/F` Erzwingt das Beenden des Prozesses.  
`/T` Beendet den angegebenen Prozess und alle untergeordneten Prozesse.  
`/PID  Prozess-ID` Gibt die ID des Prozesses an, der beendet werden soll. Verwenden Sie den Befehl TaskList, um die Prozess-ID abzurufen.  
`/U [Domäne\]Benutzer` Bestimmt den Benutzerkontext, unter dem der Befehl ausgeführt wird.
