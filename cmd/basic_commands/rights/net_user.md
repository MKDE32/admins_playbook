# SHOW
```
net user
```
Zeigt Benutzerkonten an

```
net user administrator
```
Eigenschaften des Benutzers “administrator” anzeigen



# FLAGS
`*` change pw
`/logonpasswordchg:yes` force pw change by user
`/add` add user
`/active:yes` Aktivieren des Benutzers administrator, benötigt Adminrechte
`/del` delete user
