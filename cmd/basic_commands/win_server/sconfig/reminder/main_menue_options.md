# SCONFIG Main Menu Options

| #  | Function                  | Description                                  |
|----|---------------------------|----------------------------------------------|
| 1  | Domain/Workgroup         | Join a domain or switch to workgroup         |
| 2  | Computer Name            | Rename the server                            |
| 3  | Add Local Administrator  | Add user to local Administrators group       |
| 4  | Remote Management        | Enable or disable WinRM                      |
| 5  | Windows Update Settings  | Configure update behavior                    |
| 6  | Install Updates          | Download and install updates                 |
| 7  | Remote Desktop           | Enable or disable RDP                        |
| 8  | Network Settings         | Configure IP, DNS, and network adapter       |
| 9  | Date and Time            | Set system time and timezone                 |
| 10 | Telemetry Settings       | Configure diagnostics level                  |
| 11 | Windows Activation       | Activate Windows                             |
| 12 | Log Off User             | Log out current session                      |
| 13 | Restart Server           | Reboot the system                            |
| 14 | Shut Down Server         | Power off the system                         |
| 15 | Exit                     | Exit to command line                         |
