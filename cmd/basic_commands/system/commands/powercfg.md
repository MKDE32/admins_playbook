# OVERVIEW
```
powercfg -energy
powercfg -batteryreport
powercfg -lastwake
```
- generiert einen Energiereport als xml file
- zeigt zustand des Akkus an
- zeigt warum aus energiesparmodus aufgewacht



# HIBERNATE MODE
```
powercfg -h on
powercfg -h off
```
- turns on / off
- stored in hiberfile.sys
