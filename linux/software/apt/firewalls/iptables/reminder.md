# iptables Cheat Sheet (Basics)

## 📊 Tables

| Table   | Purpose                         | Chains                                  |
|--------|---------------------------------|-----------------------------------------|
| mangle | Packet modification             | PREROUTING, INPUT, FORWARD, OUTPUT, POSTROUTING |
| nat    | Network Address Translation     | PREROUTING, OUTPUT, POSTROUTING         |
| filter | Packet filtering (default)      | INPUT, FORWARD, OUTPUT                  |
| raw    | Connection tracking exceptions  | PREROUTING, OUTPUT                      |

---

## 🔗 Chains

| Chain        | Description |
|-------------|------------|
| PREROUTING  | Packets enter before routing decision |
| INPUT       | Packets destined for local system |
| FORWARD     | Packets routed through system (not local) |
| OUTPUT      | Packets generated by local system |
| POSTROUTING | Packets leave after routing decision |

---

## 🎯 Targets / Actions

| Target       | Description |
|-------------|------------|
| ACCEPT      | Allow packet |
| DROP        | Silently drop (appears as *filtered* in nmap) |
| REJECT      | Actively reject (appears as *closed* in nmap) |
| LOG         | Log packet |
| SNAT        | Change source IP |
| DNAT        | Change destination IP |
| MASQUERADE  | Dynamic SNAT (used for NAT gateways) |
| LIMIT       | Rate limit rules |
| RETURN      | Return to previous chain |
| TEE         | Clone packet to another destination |
| TOS         | Modify Type of Service |
| TTL         | Modify Time To Live |

---

## 🔄 Stateful Connection Tracking

| State        | Description |
|-------------|------------|
| NEW         | First packet of a connection |
| ESTABLISHED | Part of an existing connection |
| RELATED     | New connection related to existing one (e.g. FTP data) |
| INVALID     | Not part of any valid connection |
| UNTRACKED   | Marked to bypass tracking (raw table) |

---

## 🧠 Notes

- Default table = **filter**
- NAT is only applied to the **first packet** of a connection
- Connection tracking is handled by **conntrack**
- Rule order matters (top → down)

---

## ⚡ Quick Examples

### Allow SSH
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

### Drop everything else
iptables -A INPUT -j DROP

### Allow established connections
iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT

### Enable NAT (internet sharing)
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
