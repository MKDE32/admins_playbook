# EXAMPLES
```
scp [options] source_file user@remote_host:/remote/path
```
local > remote

```
scp [options] user@remote_host:/remote/path local_path
```
remote > local

# FLAGS
`-r` Copy directories recursively  
`-P` port	Specify SSH port (note: uppercase P)  
`-i` identity_file	Use private key instead of password  
`-v` Verbose output (debugging)  
`-C` Enable compression for faster transfer
