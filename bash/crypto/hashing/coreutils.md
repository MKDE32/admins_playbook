# CALCULATE
```
md5sum bla.txt
sha1sum bla.txt
sha256sum bla.txt
sha512sum bla.txt
```



# SAVE
```
md5sum bla.txt > bla.txt.md5sum
sha1sum bla.txt > bla.txt.sha1sum
sha256sum bla.txt > bla.txt.sha256
sha512sum bla.txt > bla.txt.sha512sum
```



# VERIFY
```
md5sum -c bla.txt.md5sum
sha1sum -c bla.txt.sha1sum
sha256sum -c bla.txt.sha256
sha512sum -c bla.txt.sha512sum
```
