# EXAMPLES
```
ps -x
```
# FLAGS

`-x` background only

`-f` full

`-e` every user

# PROCESS STATUS

| Code  | Meaning               |
| ----- | --------------------- |
| **R** | Running               |
| **S** | Sleeping              |
| **D** | Uninterruptible sleep |
| **T** | Stopped               |
| **Z** | Zombie process        |
