# examples
## update repository
```
sudo apt-get update
```
## software upgrade
```
sudo apt upgrade    
```
## software & kernel upgrade
```     
sudo apt full-upgrade
```
## install
```
sudo apt install appname           
```
## update package manager
```
sudo apt-get install -f       
```
## uninstall
```
apt remove appname
```






# FLAGS
-f        fix dependencies  
-d        download only
